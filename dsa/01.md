## What is efficiency in programming?

Efficiency in programming means how well a program uses resources (time and memory) to complete a task.
A more efficient program does the same work faster, with less memory or fewer operations.

There are two main types of efficiency

1. Time Efficiency (Speed) ->
   `How long a program takes to run`
2. Space Efficiency (Memory Usage) ->
   `How much memory does a program uses`

## Techniques to measure time efficiency

1. Measuring time to execute -> `Use timers to calculate time`
2. Counting number of operations -> `Count no. of ops happened`
3. Abstract notion of order of growth -> `O(n)`

## What is Data Structure?

It is a way to store and organise data efficiently.

`Linear` -> stores data in sequential manner

    Array, Linked List, Stack, Queue, Hashing

`non linear` -> store data in hierarcheal or network form

    Tree, Binary Tree, Graph

# ARRAY

    Array is a Linear Data Structure used to store multiple items of same type in contineous memory location
