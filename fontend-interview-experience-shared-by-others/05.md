# 1. How do you identify and optimize a slow-loading page?

- Measure the Page Performance

  Start by identifying where the delays occur using tools such as:

  Chrome DevTools (Performance and Network tabs)

- Analyze the Bottlenecks

  Check whether the slowdown is caused by:
  - Large images that aren't compressed or appropriately sized.
  - Render-blocking CSS or JavaScript delaying page rendering.
  - Excessive JavaScript execution or unused code.
  - Slow server response time (high Time to First Byte).
  - Too many HTTP requests for scripts, fonts, and stylesheets.
  - Third-party scripts such as analytics, ads, or chat widgets.

- Optimize Frontend Performance

  Common improvements include:

  ### Images
  - Compress images.
  - Use modern formats like WebP or AVIF.
  - Lazy-load images below the fold.
  - Serve responsive image sizes.

  ### CSS
  - Minify CSS.
  - Remove unused styles.
  - Inline critical CSS.
  - Defer non-critical styles.

  ### JavaScript
  - Minify and bundle files.
  - Remove unused libraries.
  - Load scripts with defer or async.
  - Split code into smaller chunks.

  ### Fonts
  - Preload important fonts.
  - Limit font families and weights.

# 2. If an API is giving a slow response, how do you debug what the problem is?

If an API is giving a slow response in a React application, my first step is to determine whether the delay is coming from the frontend, the network, or the backend. I don't assume the API is the problem without verifying it."

"First, I open Chrome DevTools and go to the Network tab. I trigger the API call and inspect its timing. I check how long the request takes, whether it's waiting for the server response, or if the browser is spending time downloading a large payload."

"If the request itself is taking several seconds before the first byte is received, that usually indicates a backend issue. In that case, I'd share the API timing with the backend team and ask them to check server logs, database queries, or any performance bottlenecks."

"If the API responds quickly but the UI still feels slow, I investigate the frontend. I check whether I'm doing unnecessary processing after receiving the data, such as sorting or filtering large arrays, or triggering multiple re-renders in React."

"I also check whether the API is being called multiple times unintentionally. This can happen if a useEffect dependency is incorrect or if the component keeps re-rendering. React DevTools helps identify unnecessary re-renders."

"Finally, I look at the response size. If the API is returning a large amount of data, I suggest implementing pagination, filtering, or requesting only the fields needed by the frontend to reduce payload size."
