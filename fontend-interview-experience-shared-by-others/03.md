# 1. Class based vs functional components in react

| Feature               | Class Components                                           | Functional Components                    |
| --------------------- | ---------------------------------------------------------- | ---------------------------------------- |
| **Definition**        | ES6 classes that extend `React.Component`                  | Plain JavaScript functions               |
| **Syntax**            | More verbose (requires `class`, `render()` method)         | Simpler and more concise                 |
| **State Management**  | Uses `this.state` and `this.setState()`                    | Uses Hooks like `useState()`             |
| **Lifecycle Methods** | Has built-in lifecycle methods (`componentDidMount`, etc.) | Uses Hooks like `useEffect()` instead    |
| **`this` Keyword**    | Requires use of `this` (can be confusing)                  | No `this` keyword needed                 |
| **Hooks Support**     | Cannot use Hooks                                           | Fully supports Hooks                     |
| **Performance**       | Slightly heavier (more boilerplate)                        | Generally lighter and easier to optimize |
| **Code Readability**  | Can become complex for large components                    | Easier to read and maintain              |
| **Reusability**       | Logic reuse via HOCs or render props                       | Logic reuse via custom Hooks             |
| **Modern Usage**      | Less preferred in modern React                             | Preferred approach (React recommends)    |

```js
class Example extends React.Component {
  constructor(props) {
    super(props);
    this.state = { count: 0 };
  }

  render() {
    return <h1>{this.state.count}</h1>;
  }
}
```

```js
import { useState } from "react";

function Example() {
  const [count, setCount] = useState(0);

  return <h1>{count}</h1>;
}
```

# 3. what are self closing tags in html and give examples

    Self-closing tags are HTML tags that don’t need a separate closing tag because they don’t wrap any content.

    <img />
    <input />
    <br />
    <meta />
    <hr />
    <link />
