# 1. What is Debouncing in JavaScript?

Debouncing delays the execution of a function until the user stops triggering an event for a specified amount of time. If the event occurs again before the delay ends, the timer resets.

## Why do we need Debouncing?

Some events fire many times in a short period:

- typing in search boxes
- window resizing
- scrolling
- mouse movement

```js
function debounce(fn, delay) {
  let timer;

  return function (...args) {
    clearTimeout(timer);

    timer = setTimeout(() => {
      fn.apply(this, args);
    }, delay);
  };
}
// =================================
function search(value) {
  console.log("Searching:", value);
}

const debouncedSearch = debounce(search, 500);

input.addEventListener("input", (e) => {
  debouncedSearch(e.target.value);
});
```

# 2. What is Promise.all

Promise.all() is a JavaScript method that runs multiple promises in parallel and returns a single promise.

- Resolves only when all promises resolved
- It rejects immediately if any one promise rejects

```js
Promise.all([promise1, promise2, promise3]);

const p1 = Promise.resolve("React");
const p2 = Promise.resolve("JavaScript");
const p3 = Promise.resolve("TypeScript");

Promise.all([p1, p2, p3])
  .then((results) => {
    console.log(results);
  })
  .catch((err) => {
    console.log(err);
  });

// ["React", "JavaScript", "TypeScript"]
```

| Feature              | `Promise.all()`                                   | `Promise.allSettled()`                                                                             | `Promise.race()`                             |
| -------------------- | ------------------------------------------------- | -------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| **Purpose**          | Wait for **all promises** to succeed              | Wait for **all promises** to finish (success or failure)                                           | Return the **first promise** that settles    |
| **Resolves When**    | Every promise resolves                            | Every promise settles                                                                              | First promise resolves or rejects            |
| **Rejects When**     | Immediately if any promise rejects                | Never rejects because of individual promise failures (the returned promise fulfills with statuses) | Rejects if the first settled promise rejects |
| **Return Value**     | Array of resolved values                          | Array of objects (`status`, `value`/`reason`)                                                      | Value or error of the first settled promise  |
| **Execution**        | Promises run concurrently                         | Promises run concurrently                                                                          | Promises run concurrently                    |
| **Failure Behavior** | Fail-fast                                         | Collects all results                                                                               | Depends on whichever promise finishes first  |
| **Order of Results** | Same order as input                               | Same order as input                                                                                | Single first settled result                  |
| **Common Use Cases** | Multiple API calls where all results are required | Batch operations where every result matters                                                        | Timeouts, fastest response, multiple mirrors |

# 3. What is Deep Equal?

Deep equality means comparing both the values and the nested contents of two objects or arrays, instead of just comparing their memory references.

JavaScript's === compares references for objects, not their contents.

# 4. What are Event Emitters

An Event Emitter is a design pattern where an object emits named events and other parts of the application subscribe to those events. When an event is emitted, all registered listeners are executed. It enables event-driven programming and decouples different parts of the application.

# 5. What is Array.prototype.reduce()?

Array.prototype.reduce() is a JavaScript array method that reduces an array to a single value by repeatedly applying a callback function to each element.

# 6. What is Array Flattening in JavaScript?

Array flattening is the process of removing nested array levels and combining all elements into a single array. JavaScript provides the Array.prototype.flat() method for this, and it can also be implemented using reduce() or recursion.
