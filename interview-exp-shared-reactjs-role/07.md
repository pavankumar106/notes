# 1. user interface patterns

UI Pattern = What design approach you use.

### 1. Reusable Component Pattern

Instead of repeating code, create reusable components.

Benefits

- Reusable
- Easy to maintain
- Consistent UI

### 2. Container-Presentation Pattern

Separate logic from UI.

Container responsible for

- API calls
- State
- business logic

### 3. Controlled Components

React controls the input.

advantages

- validation
- easy for submission
- state sync

### 4. Uncontrolled Components

DOM controls input.

Used when

- File upload
- Third party libraries
- Performance sensitive forms

### 5. Loading Pattern

While waiting for API, show spinner or skeleton

### 6. Error State Pattern

Always handle API failures

### 7. Empty State Pattern

instead of `[]`, `show No users found.`

### 8. Pagination Pattern

- Do Not load 10K records at once
- show 10 rcords and load more as needed

### 9. Model pattern

- Instead of navigation, use pop ups

### 10. Toast notification pattern

# 2. User Interface techniques

### 1. Component Composition

Build complex UIs by combining small reusable components.

### 2. Conditional Rendering

Show UI based on conditions.

```js
if (loading) return <Loader />;

if (error) return <Error />;

return <Users />;
```

### 3. Lazy Loading

Load components only when needed.

```js
const Dashboard = React.lazy(() => import("./Dashboard"));

//=========================================================
<Suspense fallback={<Loader />}>
  <Dashboard />
</Suspense>;
```
