# 1. Explain event loop

JavaScript is single-threaded, meaning it executes one task at a time. The Event Loop continuously checks whether the Call Stack is empty. If it is, it moves pending callbacks from the Microtask Queue first, and then from the Macrotask (Callback) Queue to the Call Stack for execution. This enables asynchronous behavior without blocking the main thread.

       │     Call Stack     │

## 1. Call Stack

## 3. Callback (Macrotask) Queue

callbacks from setTimeout, setInterval goes into the macrotask queue

it waits until

## 4. Microtask Queue

Higher-priority tasks:

- Promise callbacks (.then, .catch, .finally)
- MutationObserver

Microtasks execute before macrotasks.

```js
console.log("A");

setTimeout(() => {
  console.log("B");
}, 0);

Promise.resolve().then(() => {
  console.log("C");
});

console.log("D");
// A D C B
```

| Component                   | Responsibility                                                |
| --------------------------- | ------------------------------------------------------------- |
| **Call Stack**              | Executes JavaScript functions                                 |
| **Web APIs / Runtime APIs** | Handle timers, network requests, DOM events outside the stack |
| **Microtask Queue**         | Promise callbacks, `queueMicrotask()`                         |
| **Macrotask Queue**         | Timers, DOM events, `setInterval`, `MessageChannel`           |
| **Event Loop**              | Moves tasks to the Call Stack when it's ready                 |

# 2. Implement debounce

Debouncing delays a function's execution until the user stops triggering an event for a specified amount of time. It is commonly used for search inputs, resize events, and form validation to avoid unnecessary function calls.

```js
function debounce(fn, delay) {
  let timer;

  return function (...args) {
    clearTimeout(timer);

    timer = setTimeout(() => {
      fn.apply(this, args);
    }, delay);
  };
}
```

# 3. explain closure with real world use case

A closure is a combination of a function and the lexical environment in which it was created. It allows the function to access variables from its outer scope even after the outer function has returned. Closures are commonly used for data privacy, event handlers, callbacks, memoization, and debouncing.

```js
function outer() {
  let count = 0;

  function inner() {
    count++;
    console.log(count);
  }

  return inner;
}

const counter = outer();

counter();
counter();
counter();
```

# 4. Microtasks vs Macrotasks in JavaScript

When asynchronous code executes, JavaScript places callbacks into queues. There are two important queues:

- Microtask Queue (higher priority)
- Macrotask Queue (lower priority)

The Event Loop always processes all microtasks before the next macrotask.

| Feature             | Microtask                                                                        | Macrotask                                                     |
| ------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| **Priority**        | High                                                                             | Lower                                                         |
| **Executed When**   | Immediately after the Call Stack is empty                                        | After all pending microtasks complete                         |
| **Examples**        | `Promise.then()`, `catch()`, `finally()`, `queueMicrotask()`, `MutationObserver` | `setTimeout()`, `setInterval()`, DOM events, `MessageChannel` |
| **Queue**           | Microtask Queue                                                                  | Macrotask (Callback) Queue                                    |
| **Execution Order** | Always before macrotasks                                                         | After microtasks                                              |
| **Use Cases**       | Promise chaining, small follow-up work                                           | Timers, user interactions, scheduled work                     |
