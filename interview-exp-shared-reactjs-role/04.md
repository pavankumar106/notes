# 1. A user searches for “React” and then “Redux”, but the slower React response arrives later and replaces the correct results. How would you prevent it?

"This is a race condition where an older request finishes after a newer one and overwrites the latest results. The best solution is to cancel the previous request using AbortController when starting a new search, so only the latest request can complete. If cancellation isn't possible, I track a request ID or sequence number and update the UI only if the response belongs to the most recent request. I also debounce the search input to reduce unnecessary network calls, but I wouldn't rely on debouncing alone because it doesn't prevent stale responses."

## Solution 1: AbortController (Recommended)

Cancel the previous request whenever a new search starts.

```js
import { useEffect, useState } from "react";

function Search() {
  const [query, setQuery] = useState("");
  const [results, setResults] = useState([]);

  useEffect(() => {
    if (!query) return;

    const controller = new AbortController();

    fetch(`/api/search?q=${query}`, {
      signal: controller.signal,
    })
      .then((res) => res.json())
      .then(setResults)
      .catch((err) => {
        if (err.name !== "AbortError") {
          console.error(err);
        }
      });

    return () => controller.abort();
  }, [query]);

  return <input value={query} onChange={(e) => setQuery(e.target.value)} />;
}
```

## Solution 2: Track the Latest Request ID

If cancellation isn't available, ignore stale responses.

```js
const requestId = useRef(0);

async function search(query) {
  const id = ++requestId.current;

  const response = await fetch(`/search?q=${query}`);
  const data = await response.json();

  if (id === requestId.current) {
    setResults(data);
  }
}
```

# 2. What are call, applyand bindmethods in JS?

`call()` invokes the function immediately and passes arguments one by one.

`apply()` invokes the function immediately, but arguments are passed as an array.

`bind()` does not execute the function immediately. It returns a new function with this permanently

```js
function hello(text) {
  console.log(`${text} ${this.name}`);
}

const Person = {
  name: "Pavan",
};

hello.call(Person, "Hello"); // Hello Pavan
hello.apply(Person, ["Hey"]); // Hey Pavan

const greet = hello.bind(Person);
greet("Yo"); // Yo Pavan
```
