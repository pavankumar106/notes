# 1. How does event delegation work in JavaScript? Why is it efficient?

Event delegation is a technique where a single event listener is attached to a parent element instead of multiple child elements. It works because of event bubbling, where events propagate from the target element to its ancestors. The parent uses event.target to identify the clicked child. This approach improves performance by reducing the number of event listeners, lowers memory usage, simplifies code maintenance, and automatically supports dynamically added elements.

# 2. What's the difference between event.target and event.currentTarget?

- event.target: The actual element that triggered the event.
- event.currentTarget: The element on which the event listener is currently executing.

# 3. Difference between let, const, and var. Explain hoisting and the Temporal Dead Zone (TDZ).

| Feature                                | `var`                           | `let`                 | `const`                      |
| -------------------------------------- | ------------------------------- | --------------------- | ---------------------------- |
| **Scope**                              | Function scoped                 | Block scoped          | Block scoped                 |
| **Can be redeclared?**                 | ✅ Yes                          | ❌ No                 | ❌ No                        |
| **Can be reassigned?**                 | ✅ Yes                          | ✅ Yes                | ❌ No                        |
| **Hoisted?**                           | ✅ Yes                          | ✅ Yes                | ✅ Yes                       |
| **Initialized during hoisting?**       | ✅ Initialized with `undefined` | ❌ Not initialized    | ❌ Not initialized           |
| **Temporal Dead Zone (TDZ)?**          | ❌ No                           | ✅ Yes                | ✅ Yes                       |
| **Must be initialized when declared?** | ❌ No                           | ❌ No                 | ✅ Yes                       |
| **Global object property?**            | ✅ Yes (if declared globally)   | ❌ No                 | ❌ No                        |
| **Preferred usage**                    | Rarely (legacy code)            | Variables that change | Constants and default choice |

# 4. What are closures? Explain with a real-world use case.

A closure is a function that remembers and can access variables from its outer (lexical) scope even after the outer function has finished executing.

```js
function outer() {
  let count = 0;

  return function inner() {
    count++;
    console.log(count);
  };
}

const counter = outer();

counter(); // 1
counter(); // 2
counter(); // 3
```

# 5. Explain async/await vs Promises. How does the Event Loop handle them?

| Feature            | Promises                                           | Async/Await                                       |
| ------------------ | -------------------------------------------------- | ------------------------------------------------- |
| **Syntax**         | `.then()`, `.catch()`, `.finally()`                | `async` and `await`                               |
| **Readability**    | Can become difficult with multiple `.then()` calls | Looks like synchronous code and is easier to read |
| **Error Handling** | `.catch()`                                         | `try...catch`                                     |
| **Chaining**       | Uses `.then()` chaining                            | Sequential code with `await`                      |
| **Return Value**   | Returns a Promise                                  | Always returns a Promise                          |
| **Execution**      | Asynchronous                                       | Asynchronous                                      |
| **Best For**       | Parallel operations and promise composition        | Sequential asynchronous operations                |

# 6. Deep Copy vs Shallow Copy in JavaScript objects and arrays.

| Feature                       | Shallow Copy                                       | Deep Copy                                 |
| ----------------------------- | -------------------------------------------------- | ----------------------------------------- |
| **Definition**                | Copies only the first level of an object/array     | Copies all nested levels recursively      |
| **Nested Objects**            | Shared reference                                   | Completely independent copy               |
| **Primitive Values**          | Copied by value                                    | Copied by value                           |
| **Reference Types**           | References are copied                              | New references are created                |
| **Memory Usage**              | Lower                                              | Higher                                    |
| **Performance**               | Faster                                             | Slower (depends on object size)           |
| **Changes to Nested Objects** | Affect both original and copy                      | Do not affect each other                  |
| **Common Methods**            | Spread (`...`), `Object.assign()`, `Array.slice()` | `structuredClone()`, `lodash.cloneDeep()` |

# 7. Explain debouncing and throttling. When would you use each?

| Feature        | Debouncing                                                      | Throttling                                          |
| -------------- | --------------------------------------------------------------- | --------------------------------------------------- |
| **Definition** | Executes only after the event has stopped for a specified delay | Executes at most once every specified interval      |
| **Execution**  | Waits until the user pauses                                     | Runs at regular intervals while the event continues |
| **Best For**   | Search input, form validation, auto-save                        | Scroll, resize, mouse movement, button clicks       |
| **Frequency**  | Once after inactivity                                           | Multiple times at fixed intervals                   |
| **Goal**       | Avoid unnecessary executions                                    | Limit execution rate                                |

# 8. Explain the this keyword in different execution contexts.

| Context                            | Value of `this`                                               |
| ---------------------------------- | ------------------------------------------------------------- |
| Global scope (Browser)             | `window`                                                      |
| Global scope (Node.js module)      | `{}` / `module.exports` (top-level differs by environment)    |

| Regular function (`"use strict"`)  | `undefined`                                                   |
| Object method                      | The object before the `.`                                     |
| Arrow function                     | Inherits `this` from surrounding scope                        |
| Constructor function               | Newly created object                                          |
| Class method                       | Class instance                                                |
| `call()`, `apply()`, `bind()`      | Explicitly set by the caller                                  |
| Event handler (DOM)                | The element that received the listener (for normal functions) |

# 9. Difference between map(), filter(), reduce(), forEach(), and find().

| Method          | Purpose                             | Returns                              | Modifies Original Array? | Use Case                         |
| --------------- | ----------------------------------- | ------------------------------------ | ------------------------ | -------------------------------- |
| **`map()`**     | Transform each element              | New array                            | ❌ No                    | Convert data, update values      |
| **`filter()`**  | Select matching elements            | New array                            | ❌ No                    | Search, filtering                |
| **`reduce()`**  | Reduce array to a single value      | Single value (or accumulated result) | ❌ No                    | Sum, count, grouping, flattening |
| **`forEach()`** | Execute a function for each element | `undefined`                          | ❌ No                    | Logging, side effects, API calls |
| **`find()`**    | Return the first matching element   | Element or `undefined`               | ❌ No                    | Find one item                    |
