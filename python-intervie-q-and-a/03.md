## 2. Explain the difference between is and == in Python.

### == (Equality Operator)

    == checks whether the values of two objects are equal.

    a = [1, 2, 3]
    b = [1, 2, 3]

    print(a == b) # True

### is (Identity Operator)

    is checks whether two variables refer to the exact same object in memory.

    a = [1, 2, 3]
    b = [1, 2, 3]
    c=a

    print(a is b) # False
    print(a is c) # True

## 4. What is a dictionary in Python? How does it work?

A dictionary in Python is a data structure that stores data in key–value pairs.

```py
person = {
    "name": "John",
    "age": 25,
    "city": "London"
}

print(person)
# {'name': 'John', 'age': 25, 'city': 'London'}
```

Key Characteristics of Dictionaries

    Key–Value Pair Structure
    Mutable (Can Be Modified)
    Keys Must Be Unique

How Dictionaries Work Internally

    Python dictionaries use a hash table.

    1️⃣ Python calculates a hash value of the key
    2️⃣ That hash decides where the value is stored in memory
    3️⃣ When you access the key, Python finds it very quickly

## 6. What are the different ways to create lists in Python?

1️⃣ Using Square Brackets [] (Most Common)

```py
numbers = [1, 2, 3, 4]
print(numbers) # [1, 2, 3, 4]
```

2️⃣ Using the list() Constructor

```py
numbers = list((1, 2, 3, 4))
print(numbers) # [1, 2, 3, 4]
```

3️⃣ Using List Comprehension

```py
squares = [x**2 for x in range(5)]
print(squares) # [0, 1, 4, 9, 16]
```

4️⃣ Using the range() Function

```py
numbers = list(range(5))
print(numbers) # [0, 1, 2, 3, 4]
```

5️⃣ Using List Multiplication

You can repeat elements using \*.

```py
zeros = [0] * 5
print(zeros) # [0, 0, 0, 0, 0]
```

6️⃣ Creating an Empty List

```py
a = []
b= list()
```

## 7. How does memory management work in Python?

1. Python Memory Manager

   Python has a private heap where all objects and data structures are stored.
   - The Python Memory Manager controls this heap.
   - Developers cannot directly access memory allocation.

   ```py
   x = 10

   # Python ->

   # Allocates memory in the heap
   # Stores the integer object 10
   # x references that memory location
   ```

2. Reference Counting

   Python primarily uses reference counting to manage memory.
   Each object keeps track of how many variables reference it.
   - When a variable references an object → reference count increases
   - When a reference is removed → reference count decreases
   - When reference count becomes 0, Python automatically deletes the object.

3. Garbage Collection

   Reference counting cannot handle circular references.

   ```py
   class Test:
   pass

   a = Test()
   b = Test()

   a.ref = b
   b.ref = a


   ```

   a references b

   b references a

   Even if both variables are deleted:

   The objects still reference each other, so their reference count never becomes 0.

   To solve this, Python uses a Garbage Collector that detects and removes such reference cycles.

   Python's gc module manages this process.

   ```py
    import gc
    gc.collect()
   ```

4. Python Memory Allocator (PyMalloc)

   Python uses a special memory allocator called PyMalloc for small objects.
   - Allocating memory in blocks
   - Organizing blocks into pools
   - Managing pools inside arenas

5. Generational Garbage Collection

   Python divides objects into three generations because most objects are short-lived.

   | Generation   | Description                |
   | ------------ | -------------------------- |
   | Generation 0 | Newly created objects      |
   | Generation 1 | Objects that survive Gen 0 |
   | Generation 2 | Long-lived objects         |

## 8. Explain different data types in python

| Data Type             | Description                                                                                              | Example                                 |
