# 1. Is Python a compiled language or an interpreted language?

    Python is generally considered an interpreted language, but technically it is both compiled and interpreted.

    When we write Python code, it doesn’t get executed directly.
    First, Python compiles the source code into bytecode (.pyc files). This bytecode is platform-independent.
    Then, the Python Virtual Machine (PVM) interprets that bytecode line by line and executes it.

# 2. How can you concatenate two lists in Python?

- Using the + Operator (Most Common)
  - Creates a new list
  - Original lists remain unchanged

```python
list1 = [1, 2, 3]
list2 = [4, 5, 6]

result = list1 + list2
print(result)

## [1, 2, 3, 4, 5, 6]
```

- Using .extend() Method
  - Modifies the original list
  - More memory efficient than +

```python
list1 = [1, 2, 3]
list2 = [4, 5, 6]

list1.extend(list2)
print(list1)
## [1, 2, 3, 4, 5, 6]
```

- Using += Operator
  - Similar to .extend()
  - Modifies list1

```python
list1 = [1, 2, 3]
list2 = [4, 5, 6]

list1 += list2
print(list1)
```

- Using itertools.chain() (For Large Lists)
  - Memory efficient for large datasets
  - Useful when working with iterators

```py
from itertools import chain

list1 = [1, 2, 3]
list2 = [4, 5, 6]

result = list(chain(list1, list2))
print(result)
```

# 3. Difference between for loop and while loop in Python

    A for loop is used for iterating over a sequence when the number of iterations is known,
    while a while loop runs based on a condition and is used when the number of iterations is not predetermined.

| Feature               | `for` loop              | `while` loop               |
| --------------------- | ----------------------- | -------------------------- |
| Best used when        | Iterating over sequence | condition based repetition |
| Iteration count       | Known                   | unknown                    |
| Risk of infinite loop | Low                     | High                       |
| manual update needed  | No                      | Yes                        |

```py
# for loop
for i in range(5):
    print(i)

# while loop
c = 0
while c < 5:
    print(c)
    c += 1
```

# 4. How do you floor a number in Python?

    We can floor a number using math.floor() from the math module.
    It returns the greatest integer less than or equal to the number.
    For division cases, // can also be used. However, int() should not be used for flooring negative numbers because it truncates toward zero.

- Using math.floor() (Recommended Way)

```py
import math

num = 4.7
result = math.floor(num)

print(result) # 4
```

- Using // (Floor Division)

```py
print(7 // 2) # 3
```

# 5. What is the difference between / and // in Python?

- `/` is the division operator — it performs true division and always returns a floating-point result.
- `//` is the floor division operator — it performs division and returns the result rounded down to the nearest whole number.

```py
print(7 / 2) # 3.5
print(6 / 3) # 2.0
print(7 // 2) # 3
```

# 10. How are arguments passed by value or by reference in Python?

    Python uses pass-by-object-reference, also known as call by sharing.
    The function receives a reference to the object. If the object is mutable,
    changes inside the function affect the original object. If it is immutable,
    the original object remains unchanged.

```py
# Immutable Object (int)
def modify(x):
    x = x + 10

num = 5
modify(num)
print(num) # 5

# Mutable Object (list)
def modify(lst):
    lst.append(4)

numbers = [1, 2, 3]
modify(numbers)
print(numbers) # [1, 2, 3, 4]
```

# 11. What is a lambda function?

    A lambda function is an anonymous function.
    This function can have any number of parameters but, can have just one statement.

```py
# regular function
def add(a, b):
    return a + b

# lambda function
add = lambda a, b: a + b
```

# 12. What is List Comprehension? Give an Example.

    List comprehension is a concise way to create lists in Python using a single line of code.

```py
# Without List Comprehension
squares = []
for i in range(5):
    squares.append(i * i)

print(squares) # [0, 1, 4, 9, 16]

# Using List Comprehension
squares = [i * i for i in range(5)]
print(squares) # [0, 1, 4, 9, 16]
```

# 13. What are \*args and \*\*kwargs?

- `*args` allows a function to accept any number of positional arguments.
- `**kwargs` allows a function to accept any number of keyword arguments.

```py
def add(*args):
    return sum(args)

print(add(1, 2, 3, 4)) # 10

# =======================
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(key, value)

print_info(name="Alice", age=25)
```

# 20. What is docstring in Python?

    A docstring is a documentation string written inside triple quotes immediately after a
    function, class, or module definition.

    It describes what the code does and can be accessed using
    the __doc__ attribute or the help() function.

```py
def add(a, b):
    """
    Adds two numbers and returns the result.

    Parameters:
    a (int): First number
    b (int): Second number

    Returns:
    int: Sum of a and b
    """
    return a + b
```

# 21. How is Exceptional handling done in Python?

- try -> A block of code that is monitored for errors.

- except -> Executes when an error occurs in the try block.

- finally -> Executes after the try and except blocks, regardless of whether an error
  occurred. It’s used for cleanup tasks.

```py
try:
    # Code that may cause an exception
except SomeException:
    # Code to handle the exception
else:
    # Runs if no exception occurs
finally:
    # Always runs (cleanup code)
```
