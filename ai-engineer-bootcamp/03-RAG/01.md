# RAG - Retrieval-Augmented Generation

## What is RAG

RAG, or Retrieval-Augmented Generation, is an AI architecture that enhances a language model by retrieving relevant information from external knowledge sources before generating a response. When a user asks a question, the query is converted into an embedding and used to search a vector database for the most relevant document chunks. These retrieved chunks are then provided to the LLM as context, enabling it to generate more accurate, up-to-date, and domain-specific answers while reducing hallucinations. RAG is widely used in enterprise chatbots, document search systems, and AI assistants because it allows knowledge to be updated without retraining the model

## What is a genAI appliction

A Generative AI application is an application that uses AI models like GPT, Claude, Gemini, or Llama to generate content or perform intelligent tasks based on natural language input.

## vector database

A vector database stores embeddings (numerical representations of data) and enables fast similarity search, making it a core component of Retrieval-Augmented Generation (RAG) systems.

## Similarity search

Similarity search compares the embedding of a user's query with the embeddings stored in a vector database and retrieves the most semantically similar results.

## what problem does RAG solves

RAG solves the problem of LLMs not having access to up-to-date, private, or domain-specific information by retrieving relevant data from external sources before generating a response. It also reduces hallucinations and eliminates the need for frequent model retraining.

| Problem                    | Without RAG                             | With RAG                                             |
| -------------------------- | --------------------------------------- | ---------------------------------------------------- |
| Private company documents  | ❌ Not available                        | ✅ Retrieved from knowledge base                     |
| Latest information         | ❌ Can be outdated                      | ✅ Uses current documents                            |
| Hallucinations             | ❌ More likely                          | ✅ Reduced by grounding answers in retrieved context |
| Frequent knowledge updates | ❌ Requires retraining or other updates | ✅ Update documents instead                          |
| Enterprise search          | ❌ Poor                                 | ✅ Semantic search over documents                    |
| Large document collections | ❌ Difficult to use effectively         | ✅ Retrieves only the most relevant chunks           |

## Data ingestion

Data ingestion is the process of importing data from various sources, transforming it into a usable format, and storing it for retrieval or analysis. In RAG, it involves loading documents, chunking them, generating embeddings, and storing those embeddings in a vector database.

## LangChain

LangChain is a framework for developing applications powered by large language models. It simplifies tasks like prompt management, RAG pipelines, tool calling, memory, and connecting LLMs with external data sources.

## What Can LangChain Do?

It provides components for:

- LLM integration
- Prompt templates
- RAG pipelines
- Document loading
- Text chunking
- Embeddings
- Vector database integration
- Tool calling
- Conversation memory
- Agents
- Output parsing
