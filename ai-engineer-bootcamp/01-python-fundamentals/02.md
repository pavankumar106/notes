| Feature           | List      | Tuple     | Set           | Dictionary                    |
| ----------------- | --------- | --------- | ------------- | ----------------------------- |
| Syntax            | `[ ]`     | `( )`     | `{ }`         | `{key: value}`                |
| Ordered           | ✅ Yes    | ✅ Yes    | ❌ No         | ✅ Yes (Python 3.7+)          |
| Mutable           | ✅ Yes    | ❌ No     | ✅ Yes        | ✅ Yes                        |
| Allows Duplicates | ✅ Yes    | ✅ Yes    | ❌ No         | ❌ Duplicate keys not allowed |
| Indexed           | ✅ Yes    | ✅ Yes    | ❌ No         | Access by key                 |
| Stores            | Values    | Values    | Unique values | Key-value pairs               |
| Example           | `[1,2,3]` | `(1,2,3)` | `{1,2,3}`     | `{"name":"Tony","age":40}`    |
